CampusConnect

1. Présentation et objectifs
CampusConnect est un projet visant à faciliter la consultation et la gestion des événements universitaires.
Ses objectifs sont de :
Permettre aux étudiants de découvrir les événements.
Faciliter les inscriptions.
Aider les organisateurs à gérer les événements.

2. État actuel du projet
Le projet est actuellement en phase de conception. Les User Stories et la documentation fonctionnelle sont en cours de réalisation.

3. Fonctionnalités envisagées
Consulter les événements.
Rechercher des événements.
S'inscrire à un événement.
Créer et gérer des événements.

4. Outils utilisés
Jira : gestion des User Stories et des tâches.
Confluence : rédaction de la documentation.
GitHub : stockage et partage des fichiers du projet.
